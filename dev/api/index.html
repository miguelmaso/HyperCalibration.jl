ExperimentsData

Data structures for defining an experimental test: the measurement, the loading/environmental protocol, the ambient conditions, and the specimen geometry. These four pieces are combined into an ExperimentData instance, which is the unit consumed by ConstitutiveModelling and ObjectiveFunctions.

ExperimentData{M, P, C, G}

An experiment holds a measurement M that is a function of a Protocol P -defining the independent variables- and conditionc C -environtmental static variables- and geometry G -for the reference specimen configuration-. Additionally, a weight can be assigned to the experiment to define its importance in the calibration process.

Reduced kinematics

Internal kinematic maps (deformation gradient construction, thermal Jacobian solve) used by ConstitutiveModelling to reduce a 3D constitutive model to the 1D/2D loading states of a given Kinematics (uniaxial, biaxial).

HyperCalibration.F_volumetric — Method

Return the isotropic (volumetric) deformation gradient corresponding to a given Jacobian J, i.e. $\mathbf{F} = J^{1/3} · \mathbf{I}$.

source
HyperCalibration.J_thermal — Method

Return the thermally-induced volumetric Jacobian J for a given constitutive model, evaluated either directly at a temperature θ or at the temperature extracted from an AbstractCondition.

  • Defaults to 1.0 (no thermal expansion) for any model that does not couple

volume to temperature.

  • For a thermo-mechanical model, J is instead solved by a Newton iteration

on the zero-pressure condition pressure(J) = 0

source
HyperCalibration.calculate_F — Method

Return the deformation gradient F for a given physical model and loading state, including any thermally-induced volumetric contribution computed via J_thermal.

  • calculate_F(model, θ) returns the purely volumetric F at temperature θ
  • calculate_F(model, ::Type{Uniaxial}, λ, condition) returns F for a Uniaxial stretch λ and possibly thermal condition.
  • calculate_F(model, ::Type{Biaxial}, λ, condition) returns F for a Biaxial stretch λ and possibly thermal condition.
  • calculate_F(model, λ1, λ2, condition) returns F for an independently biaxial state with stretches λ1 and λ2 under the given condition.

ObjectiveFunctions

Predefined loss functions that evaluate the mismatch between observed data and the data predicted by ConstitutiveModelling, for a given constitutive model, a set of parameters, and one or more ExperimentData. These are the functions you minimize (e.g. with Optim.jl) during calibration.

HyperCalibration.experiment_prediction — Method

Return the y_true and y_pred sampling points for a given constitutive model and experimental test.

source
HyperCalibration.normalized_mse — Method

Normalized mean squared error (MSE) loss function. Compute the loss function for a given constitutive model and one/multiple experimental tests as the weighted normalized squared difference between the predicted and the measured values.

source

Diagnostics

Statistical measures of the goodness of fit and the uncertainty of the fitted parameters.

HyperCalibration.CalibrationResult — Type
CalibrationResult

A struct that holds the results of a calibration process.

Fields

  • builder: the function to build the constitutive model (params...) -> model
  • params : the vector of optimal parameters
  • data : the dataset used to find the optimal parameters
  • model : the constitutive model

Example

result = CalibrationResult(builder, Optim.minimizer(opt_result), data)
source
HyperCalibration.ParameterStats — Type
ParameterStats

A struct returned by parameter_stats, gathering the standard errors, confidence intervals and normalized sensitivity for the calibrated parameters.

The structure implements both MIME "text/plain" and "text/latex", supporting Markdown and $\LaTeX$ rendering or copy/pasting into a document.

# REPL / Terminal:
show(stdout, MIME("text/latex"), stats)
# Rich environments (VS Code / Jupyter):
display(MIME("text/latex"), stats)

HyperCalibration.covariance_matrix — Method
covariance_matrix(calibration_result) -> (cov_mat, JtJ, sse)

Compute the cluster-robust (sandwich) covariance matrix from a CalibrationResult.

Evaluates the residual Jacobian $J_{ij} = \frac{\partial r_i}{\partial p_j}$ using central differences and aggregates residuals by experimental curve $k \in \{1, \dots, M\}$ to account for intra-curve autocorrelation:

\[\Sigma = c \cdot (J^T J)^{-1} \left( \sum_{k=1}^{M} J_k^T r_k r_k^T J_k \right) (J^T J)^{-1}\]

source
